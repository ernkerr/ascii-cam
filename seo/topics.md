# Topic queue

The weekly GitHub Action (`.github/workflows/weekly-blog.yml`, instructions in `seo/WEEKLY-POST.md`) takes the first `queued` topic, writes it, and marks it `published` with the date. A post it won't stand behind gets marked `held` with the reason. Add topics at the bottom, and check `seo/keywords.md` first so no two pages target the same query.

Status: `queued` → `published` (or `held`)

Every topic below was checked with a web search on 2026-11-04: who ranks, whether a small site can win, the page type that wins, and what ascii-cam adds. Facts in a post still have to come from `seo/context.md` > "What we can claim" or a source the run opens.
